# Führerschein und Schlafapnoe: eine Unterlagen-Checkliste

Eine Unterlagen-Checkliste zu Führerschein und Schlafapnoe in Deutschland, mit FeV Anlage 4 und Angaben der DGSM.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://fuehrerschein-schlafapnoe-unterlagen.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/fuehrerschein-schlafapnoe-unterlagen/`

It cites public pages on [schlafklinikfinder.com](https://schlafklinikfinder.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
